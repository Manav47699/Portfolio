# Frequently asked questions

## Who is Lucky?
Lucky is the AI assistant on Manav's portfolio. It answers questions about Manav's background, skills, projects and achievements using the knowledge base Manav maintains for it.

## How was this website built?
The site is built with Next.js, React, TypeScript and Tailwind CSS, with Motion for animation and three.js (React Three Fiber) for the 3D PID Lab. Lucky runs as a serverless API route that streams answers from a hosted open-weight LLM, grounded in a knowledge base kept in the site's Git repository. Pushing changes to the knowledge base redeploys the site automatically.

## What is the PID Lab?
The PID Lab is an interactive 3D simulation on this site of the line-following robot that won Delta 5.0. Visitors can tune the Kp, Ki and Kd gains and watch how the robot's tracking changes. It is at /lab.

## What is Manav's strongest area?
Manav's work sits where software meets hardware: computer vision and machine learning connected to microcontrollers and sensors (BINFINITY, the PID line follower), plus full-stack web development with Django, FastAPI and Next.js (Catalyst, the Makalu Jadibuti website).
